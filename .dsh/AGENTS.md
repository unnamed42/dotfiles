# 语言规则

* 默认始终使用简体中文进行思考（reasoning）与输出最终回答。
* 计划、工具调用、总结、代码注释同样使用简体中文。
* 仅代码、命令、文件路径、变量名、API 名称等必须原样保留的内容使用英文。
* 若某个工作区/项目的 AGENTS.md，或用户明确指定了其他语言，则以该项目级规则为准。

# Deepseek Harness 环境

* 沙箱模式下 `/tmp` 里的内容每次 bash 工具执行后会被清理。需要在多次 bash 工具执行中保留的内容，需要输出到当前工作区的临时目录。
* 沙箱模式下进程有隔离；需要使用 `ps` 工具探查其他进程时需要沙箱提权。
* 除非用户明确要求，否则不要使用 Agent Teams 功能；只在任务复杂时向用户申请使用 Agent Teams，并说明编队规划。
* 主 agent 在因 subagent/teammate 无响应而准备亲自探索前，必须先确认其是仍在运行（可能等待耗时任务）还是已异常中断；可用 `send_message` 要求其汇报当前状态。只有确认其已中止后才可自行探索，以避免重复工作。
